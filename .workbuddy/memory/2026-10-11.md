
## TUI 输入框加高 + 滚动/Logo 裁剪修复（05ef6e4）
- 根因：charWidth 把 emoji 按 1 列算，终端渲染 2 列 → 行宽超测量 → 折行 → 备屏整体上滚 → 左上角 ORCODE 字标顶部被永久裁掉。修复：emoji 按 2 列、组合符号/变体选择符/ZWJ 按 0 列、符号+FE0F（☀️）按 2 列；并且最终每一行拼接后统一钳制到屏幕宽 W，双保险杜绝折行。
- 输入框 3 行高：foot = [...busy, ...pop, inBlank, inputRow, inBlank, agRow, hintRow]；光标行号 main.length-3；命令弹层热区 popBase = H - foot.length + busyRows.length（顺带修了 busy 时热区错位的老 bug）。
- 滚动：submit/排队消息时 scrollOffset=0 回底；「还有 N 行历史」修正为 start+1（提示行本身占掉一行）；向导模式（mw）滚轮/↑↓ 不再翻主区。
- 新增 tools/smoke-width.mjs（进程内伪造 TTY：emoji 渲染、3 行输入框、帧行数=rows、滚轮后提交回底）。注意：spawn 管道模式 isTTY=false 走 legacyLoop，无头测 TUI 必须进程内伪造 TTY。

## 输入框光标 + 会话存档（30e914e）
- 光标：新增 caret（代码点索引）。insertAtCaret/backspaceAtCaret/deleteAtCaret/moveCaret/colToCaret。左右键/Home/End 在 onKey 顶部统一处理（排除 settings/picker/view 以免冲突）；鼠标点击输入行 → caret 热区（main.length-3 行）+ colToCaret 定位；渲染时终端光标列 = 4 + vlen(caret前文本），输入文本从第 4 列（' ❯ '）起。弹出层/向导/忙碌模式均可用。
- 存档：config.js 新增 SESSIONS_DIR 并在 ensureDirs 创建；/save [名] /load [文件] /sessions 三命令；snapshot() 含 transcript/replies/chatHistory/subs；每次 submit 静默写 autosave.json（崩溃后 /load autosave 恢复）。
- 测试：新增 tools/smoke-caret-save.mjs（14 项）；__OMNI_TEST 钩子扩 type/press/save/load 与 line/caret。注意：spawn 管道模式 isTTY=false 走 legacyLoop，必须用进程内伪造 TTY；单按 esc 有 60ms 计时器（processKb 的 isSingleEsc 分支），无头测 esc 清行要 await≥80ms。

## 多模型协作流水线重大升级（当前）
- 核心架构：Director 拆解 → Planner 规划 (含 waves) → Director 真实分派（签收并下发） → Workers 按波次并发执行（每波并发=min(wave大小, max_workers)） → Verifier 连续 verif_rounds 遍全部通过才输出（否则整轮回 Planner 重规划，带 gaps）。
- 配置更新：preset 默认 max_workers=3、verify_rounds=3；设置标签明确为“额定并行数”和“核实通过轮数”。
- TUI 联动：markStage 增加 dispatch 映射；routeOf 支持 dispatch→main；tuiTrace 增加 dispatch/wave/verify/replan/final 事件；workTreeLines 重绘为带箭头的有向流（Director→Planner→↩回传→Director→Workers→Verifier→Final），含动态并行岗位明细、核实进度点、回传指示。
- 报告适配：renderReport 渲染 waves、Director 分派、重规划次数、各轮核查结论。
- 测试：新增 tools/smoke-pipeline.mjs（编排器级：waves/dispatch/verify 轮次/重规划闭环）。注意：setup 时 spawns 管道模式 isTTY=false 走 legacyLoop，必须用进程内伪造 TTY 来测试 TUI 组件。
